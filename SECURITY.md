# Security Policy

## Поддерживаемая версия

Security fixes принимаются для текущей стабильной ветки 4.0.x. Старые версии не поддерживаются отдельно.

## Как сообщить об уязвимости

Если в разделе **Security** репозитория доступна кнопка **Report a vulnerability**, используйте private vulnerability reporting.

Если приватный канал недоступен, создайте публичный issue только с краткой просьбой связаться для передачи security report. Не публикуйте exploit details, персональные данные, cookies, токены, содержимое сопроводительного письма или другие секреты.

В приватном сообщении полезно указать:

- затронутую версию;
- влияние и условия эксплуатации;
- минимальные шаги воспроизведения;
- безопасный proof of concept, если он необходим;
- возможный вариант исправления.

Проект не обещает фиксированный SLA. Report будет проверен и обработан соразмерно риску и доступности maintainer.

Обычные bugs без чувствительных деталей можно сообщать через bug report template.
