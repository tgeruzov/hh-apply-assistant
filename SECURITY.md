# Security Policy

## Поддерживаемые версии

Исправления безопасности предназначены для последнего GitHub Release и текущего release-ready состояния `main`. Старые версии не поддерживаются отдельными ветками. Если проблема воспроизводится только на development commit, укажите его hash.

## Как сообщить об уязвимости

Если в разделе **Security** репозитория доступна кнопка **Report a vulnerability**, используйте GitHub private vulnerability reporting.

Если приватный канал ещё не включён, создайте публичный Issue только с просьбой о приватном контакте. Не публикуйте детали эксплуатации, cookies, токены, сопроводительные письма, персональные данные или полный diagnostic export.

Для разбора полезны:

- версия HH Apply Assistant или commit hash;
- затронутый браузер и версия Tampermonkey;
- влияние и необходимые условия;
- минимальные шаги воспроизведения;
- безопасный proof of concept или идея исправления, если они нужны.

Фиксированный SLA не заявлен. Maintainer проверяет сообщения и выбирает способ исправления с учётом риска и доступности.

## Что относится к security

Для этого проекта особенно существенны:

- выполнение кода вне заявленных `@match` или неожиданное расширение userscript permissions;
- раскрытие текста письма, данных вакансий или диагностических материалов;
- небезопасная обработка DOM/URL, позволяющая выполнить внедрённый код;
- обход cross-tab lease или generation guards, приводящий к неконтролируемым отправкам;
- подмена install/update source или другая supply-chain проблема;
- небезопасный Manual Queue или diagnostic export.

Обычная поломка селектора, неподтверждённый отклик или UI-регрессия без security impact оформляется через bug report.

## Граница доверия

Production userscript работает с `@grant none` на origin hh.ru и хранит данные в browser storage этого origin. Код hh.ru и другие скрипты в том же page context находятся в той же технической границе доступа. Tampermonkey получает обновления с URL в metadata; компрометация репозитория или release-канала поэтому является существенным риском.

Текущая модель данных и экспорта описана в [PRIVACY.md](PRIVACY.md).
