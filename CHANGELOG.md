## [4.0.0] - 2026-08-24

### Основные возможности

- Панель управления для автоматизации стандартных откликов на текущей странице hh.ru.
- Четыре режима: Безопасный, Баланс, Быстрый и Турбо.
- Настраиваемое сопроводительное письмо и лимит подтверждённых откликов за запуск.
- Ручная очередь для вопросов работодателя, предупреждений и неподтверждённых сценариев.
- Диагностика с журналом, метриками, Healthcheck и локальным экспортом.
- Русский и английский интерфейс, responsive dock/compact/overlay layout.

### Надёжность

- Отдельный v4 storage namespace и сохранение состояния между навигациями вкладки.
- Generation-aware cross-tab lease с commit guards перед необратимыми действиями.
- SPA/reload lifecycle, trap expiration и контролируемый возврат к выдаче.
- Остановка при CAPTCHA и fail-closed поведение при критических ошибках persistence.
- Строгое подтверждение успешной отправки; неясный исход передаётся в ручную очередь.

### Распространение и проверки

- Installable `hh-apply-assistant.user.js` с прямой GitHub-установкой и update metadata.
- Regression coverage для core flow, persistence, concurrency, performance и responsive docking.
- Dependency-free CI для синтаксиса, тестов, metadata, версий и локальных Markdown-ссылок.
- Документация установки, использования, архитектуры, хранения, lifecycle, diagnostics, privacy и релизного процесса.
