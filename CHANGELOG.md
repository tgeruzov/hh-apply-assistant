# Changelog

Здесь фиксируются подтверждённые изменения, которые важны пользователям HH Apply Assistant. В нормализованной продуктовой линии HH.ru Auto Responder относится к поколению 1.x, а HH Apply Assistant начинается с версии 2.0.0 и следует Semantic Versioning. Исторические public tags/releases будут нормализованы отдельно; Git commit history не переписывается.

## [Unreleased]

Пока нет изменений после 2.0.0.

## [2.0.0] - 2026-08-24

### Новое

- Проект получил название **HH Apply Assistant** и новую боковую панель, которая адаптируется к ширине окна.
- Добавлены четыре режима темпа: **Безопасный**, **Баланс**, **Быстрый** и **Турбо**.
- Интерфейс доступен на русском и английском языках.
- Добавлены настраиваемое сопроводительное письмо, лимит подтверждённых откликов и статистика запуска.
- Сценарии с вопросами работодателя, предупреждением об отказе или неясным результатом сохраняются в ручную очередь.
- Диагностика включает журнал, кнопку **Проверить страницу** и локальный экспорт отчёта для сообщения о проблеме.

### Надёжность и ограничения

- Успешный отклик засчитывается только после подтверждения; неясный результат передаётся в ручную очередь.
- Параллельный запуск в другой вкладке блокируется, а **Остановить** прекращает старый запуск.
- Работа восстанавливается после переходов между поддерживаемыми страницами hh.ru.
- При CAPTCHA или невозможности надёжно сохранить критическое состояние автоматизация останавливается.
- Скрипт обрабатывает только текущую страницу выдачи и не отвечает на вопросы работодателя автоматически.

### Совместимость и распространение

- HH Apply Assistant 2.0.0 использует независимую storage schema 1 и не импортирует настройки, историю или ручную очередь из legacy-поколения HH.ru Auto Responder. Старые данные не удаляются, но HH Apply Assistant нужно настроить заново.
- Устанавливаемый файл переименован в `hh-apply-assistant.user.js`; последующие выпуски HH Apply Assistant могут получать обновления по метаданным пользовательского скрипта.
- Код HH Apply Assistant 2.0.0 распространяется по `GPL-3.0-only`. Legacy-поколение HH.ru Auto Responder распространялось по MIT; условия уже опубликованного кода не меняются.
