# Скриншоты

Каталог зарезервирован для актуальных изображений HH Apply Assistant. До добавления файла нужно проверить, что на нём нет имени пользователя, резюме, текста письма, названий приватных поисков, vacancy query parameters и других персональных данных.

Предпочтительный формат — PNG или WebP в разумном разрешении. После добавления изображения обновите обе версии корневого README и укажите краткий alt text без маркетингового описания.
