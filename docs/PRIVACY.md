# Данные и приватность

HH Apply Assistant — локальный пользовательский скрипт, а не отдельный веб-сервис. Этот документ описывает поведение текущего исходного кода.

## Что хранится

В локальном хранилище сайта hh.ru (`localStorage`) сохраняются:

- настройки, включая текст сопроводительного письма;
- выбранный язык;
- ручная очередь: ID, URL, URL возврата, время и название вакансии;
- диагностический журнал и метрики со снимками ограниченных фрагментов страницы;
- служебная блокировка параллельного запуска и состояние свёрнутой панели.

В хранилище текущей вкладки (`sessionStorage`) находятся данные её запуска: обработанные ID, счётчики, статус работы, URL возврата, служебные блокировки, последний ID и заголовок вакансии, а также ID вкладки. Полная таблица ключей находится в [документации о хранении данных](storage.md).

Хранилище принадлежит сайту hh.ru. Поскольку скрипт работает в контексте страницы, эти данные технически доступны коду hh.ru и другим скриптам в том же контексте. Не храните секреты в поле сопроводительного письма.

## Сетевое поведение

Скрипт не использует собственные сетевые вызовы `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `sendBeacon` или `GM_xmlhttpRequest`. Он также не загружает внешний код через `@require` или `@resource` и не отправляет сохранённые данные на сервер проекта.

Tampermonkey отдельно обращается к `raw.githubusercontent.com`, чтобы установить скрипт и проверить обновления. Открытие вакансии и отправка отклика происходят через страницы и формы самого hh.ru.

## Экспорты

Диагностический отчёт создаётся локально и содержит:

- версию, время экспорта, текущий URL и user agent;
- ID вкладки, состояние запуска, счётчики и данные служебных блокировок;
- конфигурацию, где текст письма заменён только количеством символов;
- журнал с путями/параметрами страниц;
- метрики и до 15 ограниченных снимков разметки страницы.

Снимки не записывают значения полей `input`, `select` и `textarea`, но могут содержать короткие подписи элементов, `data-qa`, подсказки полей, имена полей и фрагменты текста кнопок или диалогов. Перед публикацией отчёт нужно прочитать и при необходимости отредактировать.

Экспорт ручной очереди — автономный HTML-файл. В него попадают ID вакансии, URL вакансии, URL возврата, время и название. Файл позволяет искать и открывать ссылки. Метки открытых записей по возможности сохраняются под ключом `hh_apply_assistant_s1_manual_processed`: при открытии очереди из панели они могут попасть в локальное хранилище сайта hh.ru, а у скачанного файла поведение зависит от браузера. Подробности приведены в [документации о хранении](storage.md#состояние-экспортированной-очереди).

## Удаление данных

- **Сбросить историю** удаляет обработанные ID, счётчик успешных отправок и статистику запуска в текущей вкладке.
- **Ручная очередь → Очистить** удаляет очередь.
- **Диагностика → Дополнительно → Очистить сохранённый лог и метрики** удаляет прежний журнал и метрики. После этого скрипт может создать новую служебную запись о выполненной очистке; она содержит обычные поля журнала, включая текущий путь, ID вкладки и язык.
- Для полного сброса удалите ключи `hh_apply_assistant_s1_` из `localStorage` и `sessionStorage` hh.ru либо удалите все данные сайта. Второй вариант также может завершить сессию hh.ru.

Удаление скрипта в Tampermonkey не удаляет автоматически уже сохранённые данные браузера.
