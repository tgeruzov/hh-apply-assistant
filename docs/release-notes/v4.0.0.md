# HH Apply Assistant v4.0.0

Первый публичный стабильный релиз текущей архитектуры HH Apply Assistant.

## Что вошло

- Панель для обработки стандартных откликов на текущей странице поиска hh.ru.
- Режимы Безопасный, Баланс, Быстрый и Турбо с разными интервалами действий.
- Сопроводительное письмо, лимит подтверждённых отправок и статистика запуска.
- Ручная очередь для questionnaires, reject warnings и неподтверждённых outcomes.
- Диагностика с persistent log, metrics, Healthcheck, DOM snapshots и локальным report export.
- RU/EN interface и responsive dock/compact/overlay layout.
- Generation-aware cross-tab lease, Stop fencing, SPA/full-page resume и остановка при CAPTCHA или критической persistence error.

## Установка

[Установить v4.0.0](https://raw.githubusercontent.com/tgeruzov/hh-auto-responder/v4.0.0/hh-apply-assistant.user.js)

Для Chrome 138+ в свойствах Tampermonkey должен быть включён **Allow User Scripts**. Полная инструкция находится в [docs/installation.md](../installation.md).

## Ограничения

- Скрипт обрабатывает только текущую страницу выдачи и не заполняет вопросы работодателя.
- CAPTCHA требует ручного решения и нового Start.
- Работа зависит от DOM и response flow hh.ru.
- Проект независимый и не связан с hh.ru или HeadHunter. Пользователь отвечает за соблюдение правил платформы и последствия автоматизации.
