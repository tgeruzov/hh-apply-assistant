# HH Apply Assistant v4.0.0

Первый публичный выпуск нового поколения проекта под названием **HH Apply Assistant**. Версия 4.0.0 продолжает public release history после `v3.3.0` HH.ru Auto Responder и начинает SemVer-линию HH Apply Assistant без изменения исторических tags, Releases или Git commit history.

## Главное

- Новая боковая панель адаптируется к размеру окна, а на узком экране открывается поверх страницы.
- Доступны четыре режима темпа: **Безопасный**, **Баланс**, **Быстрый** и **Турбо**.
- Интерфейс можно переключать между русским и английским языками.
- Сопроводительное письмо и лимит успешных откликов настраиваются перед запуском; статистика показывает результат текущего запуска.
- Вакансии с вопросами работодателя, предупреждением об отказе или неподтверждённым результатом сохраняются в ручную очередь.
- Экран диагностики содержит журнал, кнопку **Проверить страницу** и локальный экспорт отчёта для разбора проблем.

## Надёжность

- Успешным считается только подтверждённый отклик; неоднозначный исход не увеличивает счётчик.
- Одновременный обычный запуск в двух вкладках блокируется.
- Кнопка **Остановить** прекращает предыдущий запуск, в том числе после перехода или перезагрузки страницы.
- При CAPTCHA или критической ошибке сохранения состояния автоматизация останавливается.
- Скрипт возвращается к сохранённой выдаче после поддерживаемого сценария отклика, но не переходит на следующую страницу результатов автоматически.

## Переход с HH.ru Auto Responder

HH Apply Assistant 4.0.0 использует независимую storage schema 1 и **не переносит** настройки, историю обработанных вакансий, ручную очередь или диагностику из legacy-поколения HH.ru Auto Responder. Старые данные не удаляются, но HH Apply Assistant нужно настроить заново.

Проверьте, что старая запись **HH.ru Auto Responder** отключена или удалена: две включённые версии не должны одновременно работать на hh.ru.

Код HH Apply Assistant 4.0.0 распространяется по **GPL-3.0-only**. Legacy-поколение HH.ru Auto Responder распространялось по MIT; смена лицензии не изменяет условия уже опубликованного кода.

## Установка

[Установить v4.0.0](https://raw.githubusercontent.com/tgeruzov/hh-apply-assistant/v4.0.0/hh-apply-assistant.user.js)

1. Установите или обновите Tampermonkey.
2. В актуальном Chrome включите для Tampermonkey **Allow User Scripts**.
3. Откройте ссылку выше и подтвердите установку **HH Apply Assistant**.
4. Откройте поддерживаемую страницу поиска вакансий hh.ru и обновите её.

Полная пошаговая инструкция: [русская](../installation.md) · [English](../i18n/installation.en.md).

После установки HH Apply Assistant 4.0.0 будущие обновления могут приходить обычным механизмом Tampermonkey по метаданным скрипта. Для перехода с HH.ru Auto Responder используйте новую ссылку установки и не рассчитывайте на автоматическую замену старой записи.

## Ограничения

- Скрипт обрабатывает только текущую страницу выдачи и не заполняет вопросы работодателя.
- CAPTCHA требует ручного решения и нового запуска.
- Работа зависит от интерфейса и сценариев hh.ru; изменения сайта могут потребовать обновления userscript.
- Проект независимый и не связан с hh.ru или HeadHunter. Пользователь отвечает за соблюдение правил платформы и последствия автоматизации.
