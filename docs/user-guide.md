# Руководство пользователя

Это подробное руководство для HH Apply Assistant v4.0.0. Краткая установка и первый запуск описаны в [README](../README.md#установка).

## Панель

На широком экране панель закрепляется справа и при первом появлении открыта. Её можно свернуть в вертикальный язычок; активный прогон при этом продолжается. На узком экране интерфейс открывается как overlay и по умолчанию закрыт.

Основные элементы:

- **Старт** начинает новый прогон по текущей странице выдачи;
- **Стоп** завершает активный прогон и освобождает cross-tab lease;
- **Diagnostics** открывает журнал и проверку селекторов;
- **Сбросить историю** очищает обработанные ID и статистику текущего запуска;
- статистика показывает попытки, успешные отклики, ручные сценарии и пропуски;
- Manual Queue показывает до четырёх последних записей и общий размер очереди.

## Режимы работы

Все интервалы рандомизируются внутри выбранного профиля.

| Режим | Пауза между вакансиями | Имитация чтения | Микро-паузы действий |
|---|---:|---:|---:|
| Safe / Безопасный | 4–8 с | 15–35 с | 0,3–1 с |
| Balanced / Оптимальный | 2–5 с | 8–20 с | 0,15–0,6 с |
| Fast / Быстрый | 1,5–3 с | 4–9 с | 0,12–0,35 с |
| Turbo / Турбо | 0,08–0,2 с | отключена | 0,025–0,08 с |

Balanced используется по умолчанию. Fast и Turbo лишь повышают темп; они не дают гарантий против ограничений со стороны сайта.

## Сопроводительное письмо

Переключатель письма включён по умолчанию. Начальный текст зависит от выбранного языка интерфейса и может быть полностью заменён. Максимальная длина — 5000 символов.

Скрипт раскрывает поле письма, если оно скрыто внутри стандартной формы, и заполняет его через нативный setter textarea. При выключенном master toggle письмо не прикрепляется.

Настройка **«Откликаться при предупреждении “Скорее всего, будет отказ”» выключена по умолчанию**. При таком предупреждении вакансия переносится в Manual Queue. Включение опции разрешает скрипту продолжить только в распознанном сценарии.

## Что происходит во время прогона

1. Скрипт получает ещё не обработанные карточки текущей выдачи.
2. Открывает вакансию, имитирует просмотр в соответствии с Work Mode и ищет кнопку отклика.
3. Разбирает стандартную модалку, прямой отклик, предупреждение, форму после редиректа или анкету с вопросами.
4. Засчитывает успех только после распознанного подтверждения.
5. Сохраняет ручной сценарий в Manual Queue либо помечает вакансию пропущенной.
6. Возвращается к выдаче и переходит к следующей карточке.

Лимит относится к успешным откликам текущего запуска и может быть задан от 1 до 500. Новая страница выдачи запускается вручную.

## Manual Queue

В очередь попадают:

- анкеты с вопросами работодателя;
- вакансии с reject-warning, если принудительный отклик выключен;
- сценарии, для которых автоматическая отправка не получила надёжного подтверждения;
- другие случаи, где безопаснее передать действие пользователю.

Очередь хранится в `localStorage`, ограничена 500 записями и не добавляет дубликат по тому же ID или URL как новый итог. В панели доступны:

- **Открыть** — открыть вакансию в новой вкладке;
- **Удалить** — удалить одну запись;
- **Очистить** — очистить всю очередь;
- **Экспорт** — скачать автономный HTML-файл.

Экспорт поддерживает поиск, сортировку, режимы новых/открытых записей и массовое открытие выбранных вакансий. Если браузер открыл только одну вкладку, разрешите всплывающие окна для локального файла. Отметки «открыто» сохраняются локально в браузере, где открыт экспорт, и не синхронизируются между устройствами.

## Diagnostics

Diagnostics хранит до 1000 последних записей, группирует последовательные повторы и показывает:

- полный журнал или только ошибки;
- метрики распознанных сценариев и таймингов;
- варианты selector fallback;
- до 15 ограниченных DOM snapshots из мест сбоя;
- состояние cross-tab lease;
- результат Healthcheck ключевых селекторов.

Автопрокрутка журнала включена по умолчанию. **Очистить вид** скрывает текущий отрисованный список до следующего обновления; **Очистить всё** удаляет сохранённый журнал и метрики.

Healthcheck может вернуть:

- **OK** — основной селектор найден;
- **ЭВРИСТИЧЕСКИ НАЙДЕНО** — найден резервный вариант;
- **НЕ НАЙДЕНО** — элемент не распознан.

Поля формы письма отсутствуют на обычной выдаче, поэтому «НЕ НАЙДЕНО» для них вне открытой формы не обязательно означает поломку.

Кнопка скачивания создаёт текстовый отчёт локально. Текст сопроводительного письма заменяется сведением о его длине, а значения полей не попадают в DOM snapshots. Отчёт всё равно содержит URL/пути, user agent, состояние запуска и диагностическую разметку — проверьте и отредактируйте его перед публикацией.

## Хранение данных

Все ключи v4 используют префикс `hh_apply_assistant_v4_`. Namespace предыдущих версий не читается и автоматически не удаляется.

| Хранилище | Данные |
|---|---|
| `localStorage` | настройки и текст письма, Manual Queue, Diagnostics, метрики, cross-tab lease, состояние свёрнутой панели |
| `sessionStorage` | статус запуска, счётчик, статистика, обработанные ID, возврат к выдаче, trap lock и идентификатор вкладки |

`sessionStorage` относится к вкладке: после её закрытия история обработанных вакансий и счётчики не сохраняются. Manual Queue и настройки остаются в `localStorage`.

Cross-tab lease разрешает один штатный активный прогон. Если вкладка аварийно закрылась, lease истекает; новый запуск может потребовать короткого ожидания. Одновременные ручные изменения Manual Queue в разных вкладках не обещают транзакционного слияния.

## Обновление и сброс

У текущего `script.js` нет `@updateURL`, поэтому обновление выполняется вручную: замените код в существующей записи Tampermonkey и обновите страницу hh.ru.

- **Сбросить историю** — обработанные ID, успешные отклики и статистика текущего запуска;
- **Manual Queue → Очистить** — сохранённые ручные вакансии;
- **Diagnostics → Очистить всё** — журнал и метрики;
- удаление ключей `hh_apply_assistant_v4_` через browser DevTools — полный сброс данных скрипта.

Удаляйте только ключи скрипта: полная очистка данных hh.ru может завершить сессию на сайте.

## Решение проблем

### Панель не появилась

1. Убедитесь, что userscript включён в Tampermonkey.
2. Проверьте доступ расширения к hh.ru.
3. Проверьте, что URL соответствует одному из `@match` в `script.js`.
4. Обновите страницу после установки или изменения userscript.

### Старт не работает

Проверьте статус панели и другие вкладки hh.ru. Сообщение о занятой вкладке означает, что lease принадлежит другому активному запуску. Остановите его штатной кнопкой. Если активной вкладки уже нет, дождитесь истечения lease и повторите запуск.

### CAPTCHA

При видимой CAPTCHA или анти-бот проверке automation останавливается. Решите проверку вручную, вернитесь на поддерживаемую страницу и нажмите **Старт**. Скрипт не обходит CAPTCHA.

### Вакансия попала в Manual Queue

Это ожидаемый безопасный исход для вопросов, reject-warning при выключенной настройке и неподтверждённых сценариев. Откройте запись из очереди и завершите отклик вручную.

### Состояние после reload выглядит неверно

Нажмите **Стоп**, проверьте другие вкладки, затем обновите поддерживаемую страницу. **Сбросить историю** используйте только если хотите повторно разрешить обработку уже пройденных вакансий.

### Нужен bug report

1. Откройте Diagnostics и запустите Healthcheck на проблемной странице.
2. Воспроизведите проблему.
3. Скачайте лог.
4. Удалите персональные данные, cookies, токены и чувствительные URL/параметры.
5. Приложите минимальные шаги, browser/Tampermonkey version, Work Mode и версию HH Apply Assistant.
