# Использование

HH Apply Assistant предназначен для запуска с текущей страницы поиска вакансий hh.ru. Он обрабатывает карточки этой страницы, переходит на страницу вакансии или форму отклика и возвращается к сохранённой выдаче. Переход к следующей странице результатов выполняется вручную.

## Панель

На широком экране панель закрепляется справа и резервирует под себя место. При нехватке ширины используется compact-layout, затем overlay. Состояние открытой/свёрнутой панели сохраняется для dock/compact; overlay при смене layout открывается заново вручную.

Основные элементы русского интерфейса:

- **Запустить отклики** и **Остановить**;
- выбор режима работы;
- лимит подтверждённых откликов за запуск;
- сопроводительное письмо и разрешение пройти предупреждение HH;
- статистика: попытки, успешно, в ручной очереди, пропущено;
- **Ручная очередь** и **Диагностика**;
- **Сбросить историю**.

Интерфейс можно переключить на английский. Активный прогон продолжается при сворачивании панели.

## Настройки по умолчанию

| Настройка | Значение |
|---|---|
| Язык | Сохранённый RU/EN; иначе язык страницы/браузера, fallback — русский |
| Режим | Баланс / Balanced |
| Лимит | 50 подтверждённых откликов |
| Сопроводительное письмо | Включено |
| Текст письма | Локализованный стартовый текст из `TRANSLATIONS` |
| Отклик при предупреждении HH | Выключен |
| Панель в dock/compact | Открыта |
| Overlay | Закрыт до ручного открытия |
| Diagnostics autoscroll | Включён на время текущего document runtime |

Лимит нормализуется в диапазоне 1–500. Текст письма ограничен 5000 символами.

## Режимы

Интервалы выбираются случайно внутри профиля. Это настройки темпа, а не обещание безопасности или фиксированной производительности.

| Режим | До следующей вакансии | Имитация чтения | Паузы между действиями |
|---|---:|---:|---:|
| Безопасный / Safe | 4–8 с | 15–35 с | 0,3–1 с |
| Баланс / Balanced | 2–5 с | 8–20 с | 0,15–0,6 с |
| Быстрый / Fast | 1,5–3 с | 4–9 с | 0,12–0,35 с |
| Турбо / Turbo | 0,08–0,2 с | отключена | 0,025–0,08 с |

Скорость также зависит от загрузки страниц и ответа hh.ru. Turbo отключает имитацию чтения вакансии, но не отключает подтверждение отправки и safety guards.

## Сопроводительное письмо

При включённом переключателе скрипт ищет поле стандартной формы, при необходимости раскрывает его и заполняет через native textarea setter. Если переключатель выключен, поле письма не заполняется, но стандартный отклик без письма остаётся возможным.

Анкеты работодателя с полями `task_*` автоматически не заполняются. Они сохраняются для ручной обработки.

Настройка отклика при предупреждении «Скорее всего, будет отказ» по умолчанию выключена. В таком случае вакансия передаётся в ручную очередь. Если опция включена, принудительная отправка доступна только после надёжного распознавания этого предупреждения.

## Запуск и результаты

При свежем Start скрипт:

1. создаёт новое поколение run и занимает cross-tab lease;
2. сбрасывает счётчик успешных отправок и статистику запуска;
3. оставляет историю обработанных вакансий текущей вкладки без изменений;
4. выбирает видимые карточки, которых нет в этой истории;
5. обрабатывает их до исчерпания карточек, Stop, CAPTCHA, ошибки или достижения лимита.

Успех засчитывается только после response-specific подтверждения или доверенного post-submit перехода. Сообщение «уже откликались» не увеличивает счётчик. Неясный исход не превращается в успех по таймауту.

Статистика **Попыток** вычисляется как сумма успешных, ручных и пропущенных terminal outcomes. Она не является количеством всех DOM-кликов.

## Ручная очередь

В очередь попадают:

- анкеты с вопросами работодателя;
- reject-warning при выключенной настройке;
- формы без кнопки отправки или без надёжного подтверждения;
- ошибки/таймауты, для которых безопаснее оставить ручную запись.

Очередь хранится между сессиями и ограничена 500 записями. Повторная запись с тем же vacancy ID или URL не создаёт новый элемент; при возможности обновляется отсутствующий title.

В панели показываются две последние записи и общий размер. Можно открыть или удалить запись, очистить очередь, скачать полный HTML либо открыть интерактивное представление всей очереди. HTML поддерживает поиск, сортировку, просмотр новых/открытых элементов и массовое открытие выбранных ссылок. Браузер может потребовать разрешить несколько всплывающих окон.

## Сброс

- **Сбросить историю** удаляет processed IDs, sent counter и run statistics текущей вкладки. Лимит, настройки, ручная очередь и diagnostics остаются.
- **Ручная очередь → Очистить** удаляет все ручные записи.
- **Диагностика → Очистить всё** удаляет diagnostic log и metrics.

Точная модель хранения и полный сброс описаны в [storage.md](storage.md).
