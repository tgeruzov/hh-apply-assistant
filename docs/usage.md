# Использование

HH Apply Assistant запускается с текущей страницы поиска вакансий hh.ru. Он обрабатывает карточки только на этой странице, при необходимости открывает вакансию или форму отклика и возвращается к выдаче. Следующую страницу результатов нужно открыть вручную.

## Панель

На широком экране панель закреплена справа. При уменьшении окна она становится компактнее, а на узком экране открывается поверх страницы по вертикальному переключателю. Панель можно свернуть, не останавливая текущий запуск.

Основные элементы русского интерфейса:

- **Запустить отклики** и **Остановить**;
- выбор режима работы;
- лимит подтверждённых откликов за запуск;
- сопроводительное письмо и разрешение пройти предупреждение HH;
- статистика: попытки, успешно, в ручной очереди, пропущено;
- **Ручная очередь** и **Диагностика**;
- **Сбросить историю**.

Интерфейс можно переключить на английский. Активный прогон продолжается при сворачивании панели.

## Настройки по умолчанию

| Настройка | Значение |
|---|---|
| Язык | Сохранённый выбор; иначе язык страницы или браузера, затем русский |
| Режим | Баланс |
| Лимит | 50 подтверждённых откликов |
| Сопроводительное письмо | Включено |
| Текст письма | Стартовый текст на выбранном языке |
| Отклик при предупреждении HH | Выключен |
| Панель на широком и среднем экране | Открыта |
| Панель на узком экране | Закрыта до нажатия вертикального переключателя |
| Автопрокрутка журнала | Включена до обновления страницы |

Лимит нормализуется в диапазоне 1–500. Текст письма ограничен 5000 символами.

## Режимы

Интервалы выбираются случайно внутри профиля. Это настройки темпа, а не обещание безопасности или фиксированной производительности.

| Режим | До следующей вакансии | Имитация чтения | Паузы между действиями |
|---|---:|---:|---:|
| Безопасный / Safe | 4–8 с | 15–35 с | 0,3–1 с |
| Баланс / Balanced | 2–5 с | 8–20 с | 0,15–0,6 с |
| Быстрый / Fast | 1,5–3 с | 4–9 с | 0,12–0,35 с |
| Турбо / Turbo | 0,08–0,2 с | отключена | 0,025–0,08 с |

Скорость также зависит от загрузки страниц и ответа hh.ru. Режим **Турбо** отключает имитацию чтения вакансии, но по-прежнему проверяет результат и останавливается при CAPTCHA, ошибке или достижении лимита.

## Сопроводительное письмо

Если сопроводительное письмо включено, скрипт находит поле стандартной формы, при необходимости раскрывает его и вставляет сохранённый текст. Если переключатель выключен, стандартный отклик без письма остаётся возможным.

Анкеты с вопросами работодателя автоматически не заполняются. Такие вакансии сохраняются в ручную очередь.

Настройка отклика при предупреждении «Скорее всего, будет отказ» по умолчанию выключена. В таком случае вакансия передаётся в ручную очередь. Если настройка включена, скрипт продолжит отправку только после точного распознавания предупреждения.

## Запуск и результаты

После нажатия **Запустить отклики** скрипт:

1. сбрасывает счётчик успешных отправок и статистику нового запуска;
2. сохраняет историю уже обработанных вакансий в текущей вкладке;
3. не позволяет одновременно запустить обработку в другой вкладке hh.ru;
4. выбирает видимые карточки, которых ещё нет в истории;
5. работает до конца списка, нажатия **Остановить**, появления CAPTCHA, ошибки или достижения лимита.

Успех засчитывается только после подтверждения отправки. Сообщение «уже откликались» не увеличивает счётчик. Если результат нельзя надёжно определить, вакансия не считается успешной и обычно попадает в ручную очередь.

Статистика **Попыток** — это сумма успешных, переданных в ручную очередь и пропущенных вакансий. Это не количество нажатий на странице.

## Ручная очередь

В очередь попадают:

- анкеты с вопросами работодателя;
- предупреждения о вероятном отказе, если продолжение отключено;
- формы без кнопки отправки или без надёжного подтверждения;
- ошибки/таймауты, для которых безопаснее оставить ручную запись.

Очередь хранится между сессиями и ограничена 500 записями. Одна и та же вакансия не добавляется повторно, если совпадает её ID или URL; недостающее название может быть дополнено позже.

В панели показываются две последние записи и общий размер. Можно открыть или удалить запись, очистить очередь, скачать полный HTML либо открыть интерактивное представление всей очереди. HTML поддерживает поиск, сортировку, просмотр новых/открытых элементов и массовое открытие выбранных ссылок. Браузер может потребовать разрешить несколько всплывающих окон.

## Сброс

- **Сбросить историю** удаляет историю вакансий, счётчик успешных отправок и статистику запуска в текущей вкладке. Лимит, настройки, ручная очередь и диагностика остаются.
- **Ручная очередь → Очистить** удаляет все ручные записи.
- **Диагностика → Дополнительно → Очистить сохранённый лог и метрики** удаляет прежний журнал и метрики. После очистки может появиться новая служебная запись о самом действии.

Точная модель хранения и полный сброс описаны в [документации о хранении данных](storage.md).
