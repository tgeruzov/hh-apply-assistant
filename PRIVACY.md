# Данные и приватность

HH Apply Assistant является локальным userscript, а не отдельным веб-сервисом. Этот документ описывает поведение версии 4.0.0 по текущему исходнику.

## Что хранится

В `localStorage` origin hh.ru сохраняются:

- настройки, включая текст сопроводительного письма;
- выбранный язык;
- ручная очередь: ID, URL, URL возврата, время и название вакансии;
- diagnostic log и метрики со снимками диагностической разметки;
- cross-tab lease и состояние свёрнутой панели.

В `sessionStorage` хранятся состояние текущей вкладки и прогона: обработанные ID, счётчики, статус запуска, URL возврата, служебные locks, последний ID/заголовок вакансии и ID вкладки. Полная таблица ключей находится в [docs/storage.md](docs/storage.md).

Browser storage принадлежит origin hh.ru. При `@grant none` userscript работает в page context; данные этого origin технически доступны коду страницы и другим скриптам, работающим в той же границе. Не используйте поле сопроводительного письма как хранилище секретов.

## Сетевое поведение

Production source не вызывает `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `sendBeacon` или `GM_xmlhttpRequest`. В metadata нет `@require` и `@resource`. Сам userscript не отправляет сохранённые данные на сервер проекта.

Tampermonkey отдельно обращается к `raw.githubusercontent.com` для установки и проверки обновлений по `@updateURL`/`@downloadURL`. Это работа userscript manager, а не transport из runtime. Открытие вакансии и отправка отклика происходят через DOM, формы и навигацию самого hh.ru.

## Экспорты

Diagnostic report создаётся локально и содержит:

- версию, время экспорта, текущий URL и user agent;
- ID вкладки, run state, счётчики и данные locks;
- конфигурацию, где текст письма заменён только количеством символов;
- журнал с путями/параметрами страниц;
- метрики и до 15 ограниченных DOM snapshots.

Snapshots не записывают значения `input`, `select` и `textarea`, но могут содержать короткие подписи элементов, `data-qa`, placeholder, имена полей и фрагменты текста кнопок/диалогов. Отчёт нужно прочитать и при необходимости отредактировать перед публикацией.

Manual Queue export — автономный HTML-файл. В него попадают записи очереди: vacancy ID, URL, return URL, timestamp и title. Файл содержит интерфейс поиска и открытия ссылок; отметки открытых записей сохраняются best-effort в `localStorage` контекста экспортированной страницы.

## Удаление данных

- **Сбросить историю** удаляет обработанные ID, счётчик успешных отправок и run statistics в текущей вкладке.
- **Ручная очередь → Очистить** удаляет очередь.
- **Диагностика → Очистить всё** удаляет журнал и метрики.
- Для полного сброса удалите ключи `hh_apply_assistant_v4_` из `localStorage` и `sessionStorage` hh.ru либо удалите site data целиком. Второй вариант также может завершить сессию hh.ru.

Удаление userscript в Tampermonkey не гарантирует удаление уже записанных ключей browser storage.
