# HH Apply Assistant

Userscript для автоматизации откликов на вакансии hh.ru с плавающим HUD интерфейсом.

## Возможности
- Автоматический отклик на вакансии из поиска hh.ru с переходом в карточку и возвратом
- Плавающий HUD виджет с 3 вкладками: Настройки, Очередь, Журнал
- Очередь ручного отклика: вакансии с тестами работодателя сохраняются в отдельный список
- Редактирование сопроводительного письма прямо в интерфейсе
- Ограничение до 200 откликов в сутки согласно лимитам платформы
- Диагностический журнал событий и встроенный сторожевой таймер (watchdog)

## Установка
1. Установите расширение Tampermonkey для вашего браузера.
2. Создайте новый скрипт в панели управления Tampermonkey.
3. Скопируйте содержимое файла hh-apply-assistant.user.js и сохраните.

## Использование
1. Откройте страницу поиска вакансий: https://hh.ru/search/vacancy
2. Настройте фильтры поиска и нажмите Старт на виджете.
3. Скрипт будет последовательно обрабатывать вакансии выдачи.
