# HH Apply Assistant

**HH Apply Assistant v4.0.0** — Tampermonkey-userscript для автоматизации стандартных откликов на вакансии [hh.ru](https://hh.ru/). Скрипт добавляет справа панель управления, обрабатывает вакансии текущей страницы поиска и сохраняет сценарии, требующие участия пользователя, в Manual Queue.

[![License](https://img.shields.io/badge/license-GPL--3.0--only-blue.svg)](LICENSE)

[Установить](#установка) · [Быстрый старт](#быстрый-старт) · [Подробное руководство](docs/user-guide.md) · [Решение проблем](#решение-проблем)

После установки интерфейс появляется как боковая панель на страницах поиска и вакансий hh.ru. На узком экране панель открывается поверх страницы.

> [!WARNING]
> Это неофициальный проект для личного использования, не связанный с hh.ru / HeadHunter. Автоматизация может противоречить правилам сервиса и привести к ограничениям аккаунта. Пользователь самостоятельно выбирает темп, лимиты и принимает связанные риски.

## Что умеет

- обрабатывает вакансии на текущей странице поисковой выдачи;
- поддерживает сопроводительное письмо и формы с несколькими сценариями отклика;
- предлагает режимы Safe, Balanced, Fast и Turbo;
- ограничивает число успешных откликов за запуск;
- запускается и останавливается из панели, показывает статистику и прогресс;
- сохраняет вакансии с вопросами и другие ручные сценарии в Manual Queue;
- ведёт локальный журнал Diagnostics и экспортирует диагностический отчёт;
- поддерживает русский и английский интерфейс;
- сохраняет настройки и состояние между навигациями;
- не обрабатывает повторно уже пройденные вакансии в текущей вкладке;
- не допускает штатный одновременный запуск automation в нескольких вкладках;
- останавливается при CAPTCHA и при критической ошибке сохранения.

Скрипт работает с React-интерфейсом hh.ru, но зависит от DOM и поведения сайта. Изменения на стороне hh.ru могут потребовать обновления селекторов или логики сценария.

## Установка

### Требования

- современный десктопный браузер;
- [Tampermonkey](https://www.tampermonkey.net/) с доступом к hh.ru.

Другие userscript managers и мобильные браузеры отдельно не заявлены как поддерживаемые.

### Установка скрипта

Прямого install/update URL у текущего способа распространения нет, поэтому скрипт добавляется вручную:

1. Установите Tampermonkey и откройте его **Dashboard**.
2. Нажмите **Create a new script**.
3. Откройте [script.js](script.js), выберите **Raw** и скопируйте содержимое файла целиком.
4. Замените шаблон в редакторе Tampermonkey скопированным кодом.
5. Сохраните скрипт (`Ctrl + S`) и убедитесь, что он включён.
6. Откройте [страницу поиска вакансий](https://hh.ru/search/vacancy) и обновите её.

Панель появляется только на страницах:

- `*.hh.ru/search/vacancy*`;
- `*.hh.ru/vacancy/*`;
- `*.hh.ru/applicant/vacancy_response*`.

## Быстрый старт

1. Войдите в hh.ru и откройте выдачу с нужными фильтрами.
2. В панели **HH Apply Assistant** выберите Work Mode, проверьте лимит и сопроводительное письмо.
3. Нажмите **Старт**. Скрипт начнёт обрабатывать вакансии текущей страницы.
4. Следите за статусом и счётчиками в панели. Ручные сценарии появятся в Manual Queue.
5. Нажмите **Стоп**, чтобы прекратить прогон и освободить блокировку вкладки.

Перед первым большим запуском разумно открыть **Diagnostics** и выполнить проверку селекторов.

## Режимы работы

Режимы меняют паузы между действиями; это профили темпа, а не гарантия безопасности или успешного отклика.

| Режим | Пользовательский смысл |
|---|---|
| **Safe / Безопасный** | Самый неторопливый профиль |
| **Balanced / Оптимальный** | Умеренный темп, используется по умолчанию |
| **Fast / Быстрый** | Ускоренный профиль |
| **Turbo / Турбо** | Максимальный темп, чтение вакансии отключено |

Точные диапазоны пауз приведены в [подробном руководстве](docs/user-guide.md#режимы-работы).

## Настройки по умолчанию

Значения сверены с `script.js` для чистой установки v4.0.0.

| Настройка или состояние | По умолчанию |
|---|---|
| Язык | RU |
| Work Mode | Balanced / Оптимальный |
| Лимит успешных откликов за запуск | 50 |
| Сопроводительное письмо | Включено |
| Отклик при предупреждении «Скорее всего, будет отказ» | **Выключено** |
| Счётчики | 0 |
| Статус | Ожидание / Waiting |
| Diagnostics autoscroll | Включён |
| Панель в dock-layout | Открыта |
| Overlay на узком экране при первом появлении | Закрыт |

При выключенном отклике на предупреждение соответствующая вакансия сохраняется для ручной обработки. Production behavior не меняется ради документации: README следует фактическим defaults.

## Сопроводительное письмо

Главный переключатель письма включён по умолчанию, а поле содержит короткий стартовый текст на языке интерфейса. Текст можно заменить; максимум — 5000 символов. Если переключатель выключен, скрипт не пытается прикрепить письмо.

Письмо используется только там, где распознан подходящий стандартный сценарий. Анкеты с вопросами работодателя автоматически не заполняются и отправляются в Manual Queue.

## Manual Queue и Diagnostics

**Manual Queue** хранит вакансии, которые требуют ручных ответов, попали под выключенное предупреждение об отказе или не получили надёжного автоматического подтверждения. Из панели запись можно открыть, удалить или экспортировать вместе со всей очередью в автономный HTML-файл.

**Diagnostics** показывает журнал, ошибки, метрики сценариев и результат проверки ключевых селекторов. Отчёт скачивается локально в текстовый файл. Перед публикацией отчёта просмотрите его: текст сопроводительного письма в него не включается, но там есть технические сведения об окружении, посещённых путях/URL и снимки диагностической разметки.

Подробнее: [Manual Queue](docs/user-guide.md#manual-queue) и [Diagnostics](docs/user-guide.md#diagnostics).

## Приватность и безопасность

Текущая версия:

- не содержит внешних runtime-зависимостей, CDN, `@require` или `@resource`;
- не использует `fetch`, `XMLHttpRequest`, `WebSocket`, `sendBeacon` или `GM_xmlhttpRequest`;
- объявлена с `@grant none` и работает через DOM, навигацию и browser storage на hh.ru;
- не использует `eval`, `new Function` или динамический импорт;
- формирует Manual Queue export и diagnostic report локально через `Blob` и `URL.createObjectURL`;
- не добавляет текст сопроводительного письма в diagnostic report или DOM snapshots.

Настройки, очередь и диагностика хранятся в `localStorage`; состояние текущего прогона и история обработанных вакансий — в `sessionStorage`. Данные используют namespace `hh_apply_assistant_v4_`. Локальное хранение не заменяет осторожность: не публикуйте cookies, токены, персональные данные или диагностические материалы без проверки.

О модели хранения и технических ограничениях см. [руководство](docs/user-guide.md#хранение-данных). Для сообщения об уязвимости используйте [Security Policy](SECURITY.md).

## Ограничения

- Обрабатывается только текущая страница выдачи; переход на следующую страницу выполняется вручную.
- CAPTCHA требует ручного решения и нового запуска.
- Некоторые вакансии требуют вопросов, подтверждений или действий, которые нельзя безопасно автоматизировать; они остаются в Manual Queue.
- Изменения DOM или сценариев hh.ru могут временно нарушить работу скрипта.
- Автоматизация не гарантирует успешный отклик, просмотр резюме или ответ работодателя.
- История обработанных вакансий привязана к вкладке и очищается при её закрытии.
- Текущий ручной distribution flow не предоставляет автоматические обновления.

## Решение проблем

| Ситуация | Что проверить |
|---|---|
| Панель не появилась | Скрипт включён; Tampermonkey имеет доступ к hh.ru; открыта поддерживаемая страница; страница обновлена после установки |
| Старт не запускает прогон | Нет ли активного запуска в другой вкладке; что показывает статус; есть ли ошибки в Diagnostics |
| Обнаружена CAPTCHA | Решите проверку вручную, вернитесь на поддерживаемую страницу и снова нажмите **Старт** |
| Вакансия попала в Manual Queue | Это ожидаемо для вопросов, выключенного reject-warning и неподтверждённых сценариев; откройте запись вручную |
| После reload состояние выглядит странно | Нажмите **Стоп**, проверьте другие вкладки hh.ru, обновите страницу и запустите снова |
| Нужны данные для bug report | Выполните проверку селекторов, скачайте лог и удалите из него персональные данные перед публикацией |

Расширенная памятка находится в разделе [Troubleshooting](docs/user-guide.md#решение-проблем).

## Обновление, сброс и удаление

- **Обновление:** замените содержимое существующего userscript актуальным [script.js](script.js), сохраните и обновите вкладку hh.ru. Данные namespace v4 при замене кода не очищаются.
- **Сброс истории:** кнопка **Сбросить историю** очищает обработанные ID, счётчик отправленных и статистику текущего запуска. Manual Queue и Diagnostics очищаются отдельными кнопками в соответствующих разделах.
- **Полный сброс данных скрипта:** удалите только ключи с префиксом `hh_apply_assistant_v4_` из `localStorage` и `sessionStorage` для hh.ru. Не очищайте все данные сайта, если хотите сохранить сессию hh.ru.
- **Удаление:** удалите userscript через Tampermonkey Dashboard. Это не гарантирует автоматическое удаление уже сохранённых browser-storage ключей.
