# HH Apply Assistant

Userscript для автоматизации откликов на вакансии hh.ru.

## Возможности
- Автоматический отклик на вакансии в поисковой выдаче hh.ru
- Поддержка отправки сопроводительного письма при отклике
- Обход базовых модальных окон подтверждения
- Настраиваемые задержки между действиями для эмуляции поведения человека
- Сохранение истории обработанных вакансий в localStorage

## Установка
1. Установите расширение Tampermonkey для вашего браузера.
2. Создайте новый скрипт в панели управления Tampermonkey.
3. Скопируйте содержимое файла hh-apply-assistant.user.js и сохраните.

## Использование
1. Откройте страницу поиска вакансий: https://hh.ru/search/vacancy
2. Скрипт начнет автоматическую обработку вакансий по очереди.

## Параметры
- useCover: включить или отключить отправку сопроводительного письма
- coverText: шаблон сопроводительного письма
- delayMin / delayMax: диапазон задержки между действиями в миллисекундах
- limit: максимальное количество откликов за сессию
